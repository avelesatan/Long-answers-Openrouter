# Long-answers-Openrouter

Включение:
1) Открыть папку с игрой
2) Запустить start_proxy.bat в папке proxy

Мод проксирует запросы игры на локальный адрес и отправляет их на openrouter со снятыми ограничениями без лимитов, из-за чего не будут появляться ошибки-заглушки вроде "не разобрал ответ модели"
